# 네이버 부동산 데이터 분석기 (Naver Real Estate Data Analyzer)

이 프로그램은 네이버 부동산 API에서 아파트 거래 데이터를 가져와 분석하고 시각화해주는 도구입니다.

## 설치 및 실행 방법

1. `Naver_Real_Estate_Analyzer` 실행 파일을 다운로드합니다.
2. 다운로드한 파일을 더블 클릭하여 실행합니다.
3. 웹 브라우저가 자동으로 열리며 프로그램이 실행됩니다.

## 주요 기능

### 데이터 가져오기
- 복합 ID (아파트 단지 ID)
- 거래 유형 (매매, 전세, 월세 등)
- 연도 범위
- 지역 번호
- 데이터 타입 (요약, 테이블, 실거래가)

### 데이터 분석
- 거래 데이터 테이블 형식으로 보기
- 기본 통계 (총 거래 수, 평균 가격, 최저/최고 가격, 가격 추세)
- 원시 데이터 JSON 형식으로 보기

### 데이터 내보내기
- CSV 형식으로 다운로드
- Excel 형식으로 다운로드

## 참고 사항

- 데이터는 사용자 홈 디렉토리의 `naver_real_estate_data` 폴더에 저장됩니다.
- 프로그램을 종료하려면 콘솔 창을 닫으면 됩니다.
- 인터넷 연결이 필요합니다.

## 문제 해결

- 프로그램이 시작되지 않는 경우, 방화벽 설정을 확인하세요.
- API 오류가 발생하면 복합 ID 및 기타 파라미터를 확인하세요.

## 시스템 요구 사항

- macOS 10.13 이상 또는 Windows 10 이상
- 인터넷 연결
- 웹 브라우저 (Chrome, Firefox, Safari 등)
